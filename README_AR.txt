اقنيوا AQNIWA - مشروع Flutter لأندرويد

المحتويات:
- lib/main.dart: كود اللعبة وواجهة اللعب.
- pubspec.yaml: تعريف مشروع Flutter.
- android/: إعدادات مشروع أندرويد وGradle وManifest وMainActivity.

مهم:
هذا مشروع Flutter مصدري، وليس ملف APK جاهزًا. لبنائه يجب أن يحتوي KIencod IDE على Flutter SDK وAndroid SDK/JDK وأدوات Gradle، وأن يتيح تنزيل الحزم المطلوبة. ملف local.properties الذي يشير إلى Flutter SDK ينشأ محليًا داخل بيئة Flutter، لذلك لا يمكن تضمينه بمسار جهاز غير معروف.

اللعبة الحالية فردية تجريبية: موارد، مبانٍ، تجنيد، غزو، وأيام إنتاج. لا تحتوي على لعب أونلاين أو حفظ دائم للتقدم.
